# [SWEA 2806] N-Queen

**문제 링크:** [SWEA 2806. N-Queen](https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=AV7GKs06AU0DFAXB)

## 풀이 접근

N×N 체스판에 N개의 퀸을 서로 공격할 수 없도록 배치하는 경우의 수를 구하는 문제다.

각 행에 퀸을 정확히 하나씩 배치해야 한다는 점을 이용해, DFS의 깊이를 행 인덱스로 설정했다.

- **핵심 아이디어:** 각 행에서 퀸을 놓을 수 있는 열을 탐색하고, 배치 후 재귀 호출한다.
- **자료구조:** `int[][] board`를 사용하여 퀸의 배치 상태를 관리한다.
- **충돌 검사:** 방향 배열 `dr`, `dc`를 활용하여 8방향으로 다른 퀸이 존재하는지 확인한다.
- **상태 복원:** 재귀 호출 이후 배치했던 퀸을 제거하여 다음 경우를 탐색한다.

```java
board[depth][i] = 1;
dfs(depth + 1);
board[depth][i] = 0;
```

**비교 기준:** 직접 작성한 8방향 탐색 방식과 열·대각선 방문 배열을 사용하는 최적화 백트래킹 방식을 비교한 주관적인 평가다.

**코멘트:** 각 행에 퀸을 하나씩 배치하는 방식으로 탐색 범위를 효과적으로 제한했다. 다만 새로운 퀸을 배치할 때마다 8방향으로 보드를 검사하므로 불필요한 연산이 발생한다.

## 최적화된 풀이와 비교

| 비교 항목 | 기존 코드 | 최적화 코드 |
|---|---|---|
| 충돌 검사 | 8방향 순회 | 방문 배열 조회 |
| 충돌 검사 시간 | O(N) | O(1) |
| 보드 저장 | 2차원 배열 | 별도 보드 불필요 |
| 추가 공간 | O(N²) | O(N) |
| 백트래킹 | 사용 | 사용 |

최적화된 방식에서는 다음 세 배열만 관리하면 된다.

```java
boolean[] col = new boolean[n];
boolean[] diag1 = new boolean[2 * n - 1];
boolean[] diag2 = new boolean[2 * n - 1];
```

각 대각선을 다음과 같이 구분할 수 있다.

```java
int d1 = r + c;
int d2 = r - c + n - 1;
```

이를 이용하면 퀸을 배치할 수 있는지 O(1)에 확인할 수 있다.

```java
if (col[c] || diag1[d1] || diag2[d2]) {
    continue;
}
```
